Education Analytics: Exploring College Graduate Outcomes Using Excel

Project Overview

This project analyzes college graduate outcomes using Excel to explore relationships between college majors, median earnings, unemployment rates, and employment trends. The goal is to use data analysis to identify patterns that can help students and other decision-makers better understand the outcomes associated with different fields of study.

Business Questions

How do median earnings vary across college majors?

Which majors have higher or lower unemployment rates?

What patterns emerge when comparing earnings and employment outcomes?

How can data visualization make these findings easier to understand?

Tools and Techniques

Microsoft Excel

Data cleaning and organization

PivotTables and PivotCharts

Spreadsheet formulas and lookup functions

Data visualization

Comparative analysis and data storytelling

Key Analysis Areas

Median earnings by college major

Unemployment rates across fields of study

Comparisons of employment outcomes

Visual presentation of trends and differences

Business Value

This project demonstrates how spreadsheet-based analysis can transform raw data into understandable insights. The findings can support informed exploration of career paths and demonstrate practical skills in data analysis, visualization, and communicating results.

Important Note

The analysis identifies patterns and differences in the dataset. These findings should not be interpreted as proof that a particular college major causes a specific employment or earnings outcome.
